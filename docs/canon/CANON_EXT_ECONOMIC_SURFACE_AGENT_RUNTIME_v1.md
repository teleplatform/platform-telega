## 3) Obsolescence Trigger — когда сигнал перестанет быть актуальным

```yaml
obsolescence_trigger:
  - if: "Agent execution becomes fully local on user device"
    then: "Terminal abstraction loses economic value"
    action: "Deprecate in favor of Device-First Canon"
    impact: "Pivot to local-first pricing model"

  - if: "Regulators mandate real-time agent oversight APIs"
    then: "Zero-trust moves from feature to compliance baseline"
    action: "Absorb into Tele•Core Contract baseline"
    impact: "Remove premium pricing for zero-trust, add compliance tier"

  - if: "Open-source agent runtimes achieve feature parity"
    then: "Agent execution becomes commodity"
    action: "Pivot to value-added services (trace, policy, compliance)"
    impact: "Reduce base pricing, increase premium tier differentiation"
```
