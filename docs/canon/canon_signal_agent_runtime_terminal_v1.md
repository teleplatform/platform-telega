## 3. Core Signal (Distilled)

The observed systems confirm the following **architectural principles**:
1. **Agent is a long-living executable process**, not a request–response chatbot
2. **Execution is observable** (streamed output during runtime)
3. **Context is a controllable runtime state**, not passive chat history
4. **Dangerous actions are restricted by default** and require explicit approval
5. **Agent hierarchy is native** (sub-agents can be spawned, steered, terminated)

These principles represent a **paradigm shift from conversational AI to agent runtimes**.
