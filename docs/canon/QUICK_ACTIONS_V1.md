## 0) Goal
Add quick keyboard actions (local-only, deterministic):
- J: Jump to selected search result
- O: Open selected search result
- P: Pin/unpin current query
- /: Focus search input


## 1) Rules
- Disabled while typing in input/textarea
- Works only on local UI state (no API)
