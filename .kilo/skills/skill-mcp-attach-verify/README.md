# Skill: MCP Attach Verify

Purpose:
Provide a consistent and safe way to verify that the MCP bridge is correctly attached and operational.

Scope:
- Check MCP server visibility in Kilo
- Validate tools list
- Execute a minimal safe tool call
- Produce a clear readiness verdict

Rules:
- Do not assume success
- Only report what is observed
- Prefer exact names and outputs
- Fail clearly if any step is broken
